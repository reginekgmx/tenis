# Tenis 1976

Retro gra w tenisa w stylu konsol telewizyjnych z lat 70. — jeden plik HTML, bez instalacji.

## Jak grać

Otwórz `index.html` w przeglądarce (komputer lub telefon).

- **1 gracz** — grasz przeciw komputerowi (poziom: łatwy / średni / trudny)
- **2 graczy** — na jednym ekranie: dół i góra
- Kto pierwszy zdobędzie **11 punktów**, wygrywa

## Sterowanie

| | Dolny gracz | Górny gracz (tryb 2 graczy) |
|---|---|---|
| Klawiatura | ← → | A D |
| Dotyk / mysz | dolna połowa ekranu | górna połowa ekranu |

Spacja — pauza.
